## 1. Problem

A simple, recruiter-friendly demo: counting objects/people crossing a configurable line, with direction awareness — common in retail and traffic analytics.

## 2. Architecture

```text
Video -> Detection + Tracking -> Line-Crossing Logic -> In/Out Counters -> Overlay Output
```

## 3. Technology Stack

- Python
- YOLO
- OpenCV
- ByteTrack

## 4. Feature List

- Object detection
- Tracking
- Configurable counting line
- Direction detection (in/out)
- Incoming count
- Outgoing count
- Live visualization overlay

## 5. Implementation Plan

1. Phase 1: Detection + tracking baseline
2. Phase 2: Configurable line and crossing-direction logic
3. Phase 3: Live counter overlay and export of counts
